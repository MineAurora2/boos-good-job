# 统计面板网站图标设计

## 目标

为“求职雷达”统计面板制作一套统一的网站图标，替换浏览器标签页图标和侧边栏左上角现有的三柱品牌标记。图标需在 16 像素 favicon 尺寸下保持清晰，并与面板现有的深色、青绿数据可视化风格一致。

## 已确认方向

采用“趋势脉冲”图形：三根由低到高的数据柱配一条向右上方延伸的趋势线。

- 深色圆角方形底：`#0F2230`
- 前两根数据柱：`#39D7F2`
- 最高数据柱：`#56D9A5`
- 上升趋势线：`#EEF8FB`
- 不包含文字、阴影装饰或小尺寸下无法辨认的细节
- 保留侧边栏中的“求职雷达 / JOB OPS”文字，只替换图形标记

## 资产结构

`dashboard/assets/` 保存正式图标资产：

- `favicon.svg`：单一设计源和侧边栏显示资产
- `favicon.ico`：包含常见 favicon 尺寸，供兼容环境使用
- `favicon-32x32.png`：32 像素浏览器图标
- `favicon-16x16.png`：16 像素浏览器图标

SVG 使用固定 `viewBox`，通过简单几何形状绘制背景、数据柱和趋势线。ICO 与 PNG 从同一 SVG 设计导出，避免不同格式之间出现视觉偏差。

## 页面接入

在 `dashboard/index.html` 的 `<head>` 中声明 SVG、ICO 和 PNG favicon。现代浏览器优先使用 SVG，兼容环境可回退到 ICO 或 PNG。

侧边栏 `.brand-mark` 改为引用 `favicon.svg` 的图片元素。现有品牌文字、布局间距和导航结构保持不变；样式只调整图标容器和图片尺寸，确保深色与浅色主题下均有足够对比度。

## 兼容与失败处理

所有图标使用站点现有的 `/dashboard/` 静态资源路径。即使浏览器不支持 SVG favicon，也可回退到 ICO 或 PNG。侧边栏图片提供空替代文本并保持 `aria-hidden="true"`，因为相邻文字已经表达品牌含义。

## 验收标准

- 浏览器标签页能加载新图标，不产生 404 请求。
- 16、32、64 像素下，三根数据柱和上升趋势仍可辨认。
- 侧边栏图标替换现有三柱标记，品牌文字和布局不发生跳动。
- 深色与浅色主题下图标边缘、柱形和趋势线均有清晰对比。
- SVG、PNG 与 ICO 使用相同构图和颜色。
- 相关静态页面测试通过，项目相关进程在验证后关闭。

## 非目标

- 不重设计侧边栏品牌文字或其他导航图标。
- 不修改统计面板的主题色变量。
- 不为图标加入动画、文字或额外品牌口号。
